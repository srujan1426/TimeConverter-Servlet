# Time Converter (Seconds to H:M:S)

## Name:
Srujan

## Project Title:
Time Converter using Java Servlet

## Description:
This project is a web application developed using Java Servlets.

The user enters time in seconds, and the application converts it into:
- HH:MM:SS format
- Total minutes
- Total milliseconds

## Technologies Used:
- Java Servlet
- HTML
- Apache Tomcat
- Eclipse IDE

## How it works:
1. User enters seconds in the input field
2. Servlet processes the input
3. Displays converted time in multiple formats
